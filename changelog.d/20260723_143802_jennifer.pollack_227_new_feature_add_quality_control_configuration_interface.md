### Internal changes

- Introduced the initial quality control package structure and
  configuration framework, including typed configuration objects,
  YAML parsing, and validation for quality metrics, rejection
  policies, and reporting.
- Extended the quality control configuration framework with configurable
  resource declarations and metric resource requirements, including
  validation of resource references and consistency between quality metrics
  and rejection policies.

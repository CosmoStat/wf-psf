### Internal changes

- Unit tests for `SimulationDataLoader` covering initialisation,
  load workflow, and dataset structure validation.
- Unit tests for `TensorFlowDatasetConverter` covering `convert_dict()`,
  `convert_inference_data()`, and `process_seds()`.
- Skipped deprecated `DataHandler` and `DataConfigHandler` tests pending removal in a future
  PR once all downstream consumers are updated.
- Added minimal backward compatibility smoke test for deprecated
  `DataHandler` to verify existing behaviour is preserved.
- Added pytest markers `deprecated`, `slow`, `integration`, and `unit`
  to `pyproject.toml` to support selective test execution.

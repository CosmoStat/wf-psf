### Breaking changes

- Replace the separate `x_field`, `y_field`, `SED`, `source`, and `mask` arguments to `PSFInference` with the unified `PSFDataset` input container.
- The inference dataset schema now requires positions and seds.

### New features

- Add the public `generate_psf_models()` API for generating PSF models from a `PSFDataset` and inference configuration.
